SandClaw.ai PeerShare Proxy (Chrome extension) — changes
=========================================================

0.2.0 — 2026-11-18

  Added
  - "Allow any website" (popup, Advanced; off by default, marked RISKY):
    relays to any http(s) URL, not only this computer and private
    networks, for PeerShare services set to "Any URL, through the browser
    extension". Still without cookies. Only the popup can turn it on; a
    refused public URL now says where the switch is.
  - Tells the page whether "Allow any website" is on.

  Fixed
  - POST, PUT and PATCH requests to a local service failed with an empty
    502: the body was sent on as a stream, which Chrome only does over
    HTTP/2, and local services speak HTTP/1.1. The body now goes on whole.
  - A 502 for an unreachable service now says why in its body.

0.1.1 — 2026-11-13

  Added
  - Says which build it is: its git commit next to its version, in the
    popup and to the PeerShare page, whose diagnostics name it.

0.1.0 — 2026-11-13

  First release: the PeerShare proxy's job, done by a browser extension
  instead of a script.
  - Relays the PeerShare page's requests to services on this computer and
    private networks (localhost, 10/8, 172.16/12, 192.168/16, 100.64/10,
    IPv6 unique-local); refuses everything else, and .local names.
  - Answers only https://peershare.sandclaw.ai and pages on localhost and
    127.0.0.1.
  - HTTP only: no WebSockets, no per-guest cookie jars; redirects are
    followed.
